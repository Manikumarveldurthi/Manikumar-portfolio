# 🌐 Personal Portfolio Website

A responsive personal portfolio website developed to showcase my projects, technical skills, certifications, education, achievements, and professional experience. The portfolio serves as a central hub for recruiters, hiring managers, and developers to explore my work and technical capabilities.

The website highlights my Full Stack Development, Java, React, Python, and AI-based projects while providing quick access to my resume, GitHub profile, LinkedIn profile, and contact information.

---

## 📌 Project Overview

This portfolio website was designed to create a professional online presence and provide a centralized platform for showcasing academic projects, technical skills, certifications, internships, and achievements.

The application features a clean and responsive design optimized for desktop, tablet, and mobile devices.
